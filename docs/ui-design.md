# Ninna 界面设计与状态约定

## 设计方向

MANAS Create 模式。画布 `#FFFCF5`，辅面 `#FCF8EE`，浮层 `#FFFEFA`。连续表面、安静分隔、清晰主动作。后台实现保持单体，前端作为完整产品交付。

产品级导航分为工作台、训练定义、执行环境。对象详情保持返回路径、对象名称、版本、状态和持久动作的位置一致。每次重新训练创建新 Run，不改变历史记录。

## 页面范式

| 页面 | 主范式 | 主任务 | 窄屏优先级 |
| --- | --- | --- | --- |
| Runs | 列表与搜索 | 查找运行、继续观察、发起训练 | 名称、状态、结果、查看入口 |
| 创建训练 | 设置与表单 | 组合训练资产和执行环境 | 先训练定义，后环境，最后提交摘要 |
| Run 详情 | 实时工作台 | 观察训练，处理失败，获取产物 | 状态和动作常显，指标、日志、诊断用标签切换 |
| 资产 | 列表与搜索 / 内容详情 | 查看资产版本及可训练内容 | 识别字段和版本，长标识可换行 |
| 比较 | 列表与搜索 | 对齐定义差异和结果 | 对比表局部横滚 |
| Certification | 实时工作台 | 验证完整训练链路 | 检查进度和失败证据，关联信息随后展示 |

## 页面状态矩阵

| 真实状态 | 来源 | 可见信息与动作 | 恢复与清理 |
| --- | --- | --- | --- |
| 首次加载 | GET 未完成 | 加载提示 | 响应后显示内容 |
| 空资产 / 空运行 | API 返回空列表 | 原因说明、初始化或创建入口 | 初始化后刷新 |
| 请求失败 | 网络或 API 错误 | 就近错误、重试 | 成功后清除错误 |
| 后台刷新失败 | 轮询失败 | 保留已有数据，提示连接中断 | 自动重试，不推断 Run 已停止 |
| 提交中 | POST 未完成 | 按钮禁用、防重复操作 | 失败保留输入，成功跳转新 Run |
| CREATED / PREPARING | Run status | 等待或准备；可取消 | 状态来自平台 |
| RUNNING | Run status + events | 真实曲线、日志、取消 | 不绘制占位训练结果 |
| SUCCESS | Run status | 指标、下载、Model 晋升 | 历史不可编辑，可新建 |
| FAILED | Run status + stderr | 失败原因、诊断、新建入口 | 新 Run 独立于旧错误 |
| CANCELLED | 平台取消 | 已取消、保留日志 | 新建训练 |
| Certification RUNNING | 验收记录 | 已完成检查、关联 Run | 页面离开不停止任务 |
| Certification PASS / FAIL | 验收结果 | 明确结果与逐项证据 | 再次运行创建新验收记录 |

## 控件清单

| 控件 | 语义 | 规格与状态 |
| --- | --- | --- |
| 列表搜索 | 查询 | 中等宽度，清楚标签，空查询等于全部 |
| 状态筛选 | 有限选择 | 文本标签与下划线选中 |
| 资产选择 | 枚举 | 名称 + 版本，空值不能提交 |
| CPU / 内存 | 短参数 | 有限数字输入，不等宽填满页面 |
| Model 新版本 | 短标识 | 校验错误就近展示，不覆盖原版本 |
| 取消训练 | 对象动作 | 原生 dialog 确认，返回焦点 |
| stdout / stderr | 通道选择 | 分段选择，保留可访问名称 |
| 日志跟随 | 布尔状态 | 按钮 pressed 状态，上翻停止跟随 |
| 文件路径和 hash | 长内容 | 等宽、复制友好、详情可完整查看 |

## 验证

Playwright 覆盖真实页面导航、表单、320/768/1280/1440px、横向溢出、移动导航焦点返回。axe 检查 WCAG 2.2 AA 相关规则。额外检查真实运行详情、失败页、键盘操作、200% 缩放与 reduced-motion。截图位于 `outputs/ui-evidence`；工程测试与视觉验证分别记录。

## 中心存储与实验观察（feature/kohakuhub-aim）

沿用纸白淡金底色、细分隔线、橄榄色主操作。中心存储使用“资产目录 + 结构化操作”范式；实验观察使用“实验选择 + 数据画布”范式。

| 页面 | 真实数据 | 状态与恢复 |
| --- | --- | --- |
| 中心存储 | KohakuHub HF API、持久化传输记录 | 未启用、连接中、已连接、服务不可用；令牌输入留空保留；失败可重试 |
| 发布/导入 | 本地 HF 资产、远端 commit、SHA-256 清单 | 排队、传输中、成功、失败；新版本冲突明确报错；从历史记录找到结果 |
| 实验观察 | Aim SDK 元数据与时序数据 | 首次加载、无实验、无指标、记录暂停、同步异常、正常曲线 |
| 实验比较 | 最多四个真实 Aim Run | 按 epoch 对齐，缺失点不连接，显示原始值表、Aim hash、原 Run 链接 |

控件：显式 label 的输入/选择框；密码字段不回显令牌；Hub 开关与 Aim 开关独立；仓库选择只填充导入表单，由用户提交；主操作显示等待状态。移动端改为纵向布局并保留实验筛选、选择、曲线和原始值表。没有 iframe，也不启动 Aim 自带 Web UI。
