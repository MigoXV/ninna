# Ninna 界面设计与状态约定

## 设计方向

MANAS Refine 模式。画布 `#FFFEFB`，辅面 `#FCFCFA`，浮层 `#FFFFFF`。大面积接近纯白，只保留极轻的暖金倾向；正文、边界与选中态使用中性灰。连续表面、安静分隔、清晰主动作。

产品级导航分为工作台、训练定义、执行环境。对象详情保持返回路径、对象名称、版本、状态和持久动作的位置一致。每次重新训练创建新 Run，不改变历史记录。

## 页面范式

| 页面 | 主范式 | 主任务 | 窄屏优先级 |
| --- | --- | --- | --- |
| Runs | 列表与搜索 | 查找运行、继续观察、发起训练 | 名称、状态、结果、查看入口 |
| 创建训练 | 设置与表单 | 组合训练资产和执行环境 | 先训练定义，后环境，最后提交摘要 |
| Run 详情 | 实时工作台 | 观察训练，处理失败，获取产物 | 状态和动作常显，指标、日志、诊断用标签切换 |
| 资产 | 列表与搜索 / 内容详情 | 查看资产版本及可训练内容 | 识别字段和版本，长标识可换行 |
| 比较 | 列表与搜索 | 对齐定义差异和结果 | 对比表局部横滚 |
| Certification | 实时工作台 | 验证完整训练链路 | 检查进度和失败证据，关联信息随后展示 |

## 页面状态矩阵

| 真实状态 | 来源 | 可见信息与动作 | 恢复与清理 |
| --- | --- | --- | --- |
| 首次加载 | GET 未完成 | 加载提示 | 响应后显示内容 |
| 空资产 / 空运行 | API 返回空列表 | 原因说明、初始化或创建入口 | 初始化后刷新 |
| 请求失败 | 网络或 API 错误 | 就近错误、重试 | 成功后清除错误 |
| 后台刷新失败 | 轮询失败 | 保留已有数据，提示连接中断 | 自动重试，不推断 Run 已停止 |
| 提交中 | POST 未完成 | 按钮禁用、防重复操作 | 失败保留输入，成功跳转新 Run |
| CREATED / PREPARING | Run status | 等待或准备；可取消 | 状态来自平台 |
| RUNNING | Run status + events | 真实曲线、日志、取消 | 不绘制占位训练结果 |
| SUCCESS | Run status | 指标、下载、Model 晋升 | 历史不可编辑，可新建 |
| FAILED | Run status + stderr | 失败原因、诊断、新建入口 | 新 Run 独立于旧错误 |
| CANCELLED | 平台取消 | 已取消、保留日志 | 新建训练 |
| Certification RUNNING | 验收记录 | 已完成检查、关联 Run | 页面离开不停止任务 |
| Certification PASS / FAIL | 验收结果 | 明确结果与逐项证据 | 再次运行创建新验收记录 |

## 控件清单

| 控件 | 语义 | 规格与状态 |
| --- | --- | --- |
| 列表搜索 | 查询 | 中等宽度，清楚标签，空查询等于全部 |
| 状态筛选 | 有限选择 | 文本标签、轻量填充与 pressed 状态 |
| 资产选择 | 枚举 | 名称 + 版本，空值不能提交 |
| CPU / 内存 | 短参数 | 有限数字输入，不等宽填满页面 |
| Model 新版本 | 短标识 | 校验错误就近展示，不覆盖原版本 |
| 取消训练 | 对象动作 | 原生 dialog 确认，返回焦点 |
| stdout / stderr | 通道选择 | 分段选择，保留可访问名称 |
| 日志跟随 | 布尔状态 | 按钮 pressed 状态，上翻停止跟随 |
| 文件路径和 hash | 长内容 | 等宽、复制友好、详情可完整查看 |

## 验证

Playwright 覆盖真实页面导航、表单、320/768/1280/1440px、横向溢出、移动导航焦点返回。axe 检查 WCAG 2.2 AA 相关规则。额外检查真实运行详情、失败页、键盘操作、200% 缩放与 reduced-motion。截图位于 `outputs/ui-evidence`；工程测试与视觉验证分别记录。

## 中心存储与实验观察（feature/kohakuhub-aim）

沿用近白金底色、细分隔线、深灰主操作。中心存储使用“资产目录 + 结构化操作”范式；实验观察使用“实验选择 + 数据画布”范式。

| 页面 | 真实数据 | 状态与恢复 |
| --- | --- | --- |
| 中心存储 | KohakuHub HF API、持久化传输记录 | 未启用、连接中、已连接、服务不可用；令牌输入留空保留；失败可重试 |
| 发布/导入 | 本地 HF 资产、远端 commit、SHA-256 清单 | 排队、传输中、成功、失败；新版本冲突明确报错；从历史记录找到结果 |
| 实验观察 | Aim SDK 元数据与时序数据 | 首次加载、无实验、无指标、记录暂停、同步异常、正常曲线 |
| 实验比较 | 最多四个真实 Aim Run | 按 epoch 对齐，缺失点不连接，显示原始值表、Aim hash、原 Run 链接 |

控件：显式 label 的输入/选择框；密码字段不回显令牌；Hub 开关与 Aim 开关独立；仓库选择只填充导入表单，由用户提交；主操作显示等待状态。移动端改为纵向布局并保留实验筛选、选择、曲线和原始值表。没有 iframe，也不启动 Aim 自带 Web UI。

## 近白金与可收缩导航（feature/near-white-gold-ui）

[Figma 设计文件](https://www.figma.com/design/ab3EG1a9aEHNyNZRJCzmD4) 包含 22 个独立界面 Page、1 个规范 Page 和 2 个组件 Page。每个 Page 只有一个位于原点的主画板；桌面界面主要展示工作视口，移动端保留自然文档长度。文字、向量、布局均可编辑，导航和重复控件使用组件实例。

规范页保留纯白/旧画布/新画布对照。两层变量共 56 个（含新版导航辅助色和选中色），WEB syntax 对应 CSS 变量；组件页包含按钮/导航/侧栏状态集及 16 个页面控件。领域色分别用于 Dataset（青）、Model（蓝）、Recipe（金）、Runtime（紫）、Workspace（灰绿），仅作辅助识别。

逐页索引见 [figma-pages.json](figma-pages.json)，可打印的 [A3 横向审阅稿](design/ui-v0.5.0-review.pdf) 包含目录、页码及长界面续页。普通桌面稿展开导航，第 22 页单独展示收起状态。

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| canvas | `#FFFEFB` | 近白金画布，RGB 通道最大差仅 4 |
| surface | `#FCFCFA` | 侧栏、表头等极浅辅面 |
| hover | `#F7F7F4` | 交互反馈与细标记配合 |
| selection | `#F1F2EE` | 中性选中/禁用辅面 |
| text / muted | `#282B29` / `#686B65` | 正文和辅助文字 |
| line / control-line | `#E7E8E2` / `#8D9387` | 普通分隔和可操作输入边界 |
| action / accent | `#343A34` / `#776A46` | 深灰主操作和克制的焦点标记 |

旧米黄填充、棕色文字和金色边框归并为共享颜色角色。表格、计数、资产图标、架构条目、代码树、Hub 设置和实验选择项采用轻量表面。按钮保持 42px 高度、5–6px 圆角；成功/失败仍用文字与图标表达，颜色只作辅助。图表网格和浮层同步引用主题变量。

| 导航状态 | 来源 | 表现与恢复 |
| --- | --- | --- |
| 桌面展开 | 默认或展开按钮 | 现有分组、图标与文字，收起按钮常显 |
| 桌面收起 | 收起按钮；localStorage 保存偏好 | 72px 图标栏；当前位置极浅填充；hover/focus 提示名称；Escape 关闭提示 |
| 刷新/切换路由 | 浏览器偏好 | 保留收起状态；无法写存储时当前会话仍可切换 |
| 窄屏抽屉 | ≤640px，打开导航 | 完整文字标签；关闭后不进入键盘顺序；Escape 关闭并返回焦点 |
| 抽屉中切回桌面 | media query change | 关闭抽屉并解除主体 inert，恢复桌面偏好 |

侧栏按钮为真实 button，带 `aria-expanded` / `aria-controls`；图标导航始终有可访问名称。侧栏内容独立滚动，焦点环放在导航项内部避免裁切。原有路由、数据契约、训练创建和失败恢复行为保留。

实测对比度：正文 14.19:1、辅助文字 5.37:1、输入边界 3.13:1、焦点色 5.29:1、主操作文字 11.66:1。近白色背景的辨识度与屏幕色温有关，因此 Figma 中保留纯白对照。

## 工作区滚动与字体（ui-v0.4.0）

桌面训练列表与详情固定标题和工具区，内容区域独立滚动；列表返回恢复位置，不同 Run 和详情标签分别保存位置。窄屏与低高度视口使用文档滚动。标题、指标与资产卡片收紧；Inter、Noto Sans SC 和 IBM Plex Mono 随应用本地提供。中心存储区分首次检查、连接成功、未启用与实际失败，避免加载时闪现错误。

本版验证结果、截图目录和 Figma 同步记录见 [UI 发布记录](ui-releases.md)。

## 项目工作区（ui-v0.5.0）

首页为 Project 目录，提供搜索、新建、说明与运行数。进入项目后查看运行及项目内实验比较。准确率与 loss 留在 Run 详情及主动选择的项目内比较中，不在首页或运行列表汇总不同模型的指标。系统验收从产品导航、界面、API、CLI 与 MCP 工具中移除，回归测试留在开发目录。

Figma 的原验收 Page 替换为项目目录，移动到规范页之后；22 个界面均为单个原点画板。旧运行通过组织索引归入 legacy；执行记录和模型产物保持不变。
